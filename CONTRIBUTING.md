# Contributing to Dawahnig Live

Thank you for considering contributing to this project!

## How to Contribute

1. **Fork the repository** on GitHub to your own account.
2. **Create a new branch** off of `main` with a descriptive name for your change.
3. **Make your changes** and commit them with clear messages.
4. **Open a pull request** against the `main` branch of this repository and describe your changes.

Please also review our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and [SECURITY.md](SECURITY.md) before getting started.
